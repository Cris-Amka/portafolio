# Portafolio Web 🚀

Colección de proyectos interactivos de desarrollo frontend creados con HTML, CSS y JavaScript puro para poner en práctica la lógica de programación, la manipulación del DOM y el diseño de interfaces.

## 📂 Proyectos incluidos

* **Calculadora (`calculadora`):** Aplicación web funcional para realizar operaciones aritméticas básicas, con manejo de eventos y diseño limpio.
* **Piedra, Papel o Tijera (`juego`):** Juego interactivo contra la computadora que incluye selección de jugadas, lógica de resultados y marcador de puntuación en vivo.

## 🛠️ Tecnologías utilizadas

* **HTML5:** Estructura semántica de las vistas (`html/`).
* **CSS3:** Estilos personalizados y diseño visual (`css/`).
* **JavaScript:** Lógica de cálculo, control de flujo y dinamismo en el navegador (`js/`).
